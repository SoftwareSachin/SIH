# Detailed pipeline (step by step)

1. **Ingest & Preprocess**

   * Accept PDFs / multipage TIFFs / scanned images.
   * Preprocess each page: deskew + denoise + contrast stretching + binarize + optionally apply real-ESRGAN for tiny text.
   * Tools: OpenCV, ImageMagick, Pillow, real-ESRGAN (local GPU).

2. **Page classification & script detection**

   * For each page detect: printed vs handwritten dominant, and script (Devanagari, Latin, Odia, Telugu, etc.).
   * If mixed, split into regions (table vs margin notes) using layout segmentation (detect text regions via morphological ops or PaddleOCR layout model).

3. **Text recognition**

   * **Printed regions:** run PaddleOCR/EasyOCR (multi-script).
   * **Handwritten regions:** run TrOCR (Hugging Face) or Calamari/Kraken. Fine-tune TrOCR on local labelled handwriting samples from FRA documents.
   * Keep per-line bounding boxes and confidence scores.

4. **Layout parsing + structured extraction**

   * Combine OCR outputs with page image into **LayoutLMv3** or **Donut** to extract fields: village, patta id, applicant name, claim status, coordinates, date, remarks.
   * LayoutLMv3: uses OCR token boxes + image embeddings → trainable to output token classification or span extraction.
   * Donut: image→JSON direct mapping (OCR-free) — useful where OCR is very noisy but needs lots of training data.

5. **NER & postprocessing**

   * Run a fine-tuned transformer NER model (spaCy with transformer backend or HF pipelines) to label PERSON, LOCATION, ID, STATUS.
   * Normalize addresses / village names using a gazetteer (local DB of villages/districts), normalize coordinates (lat/lon) and verify by reverse geocoding against local shapefiles.
   * For coordinates found as text, parse numeric patterns and validate within the containing village polygon.

6. **Confidence & human review loop**

   * For each extracted record compute an overall confidence (weighted: field confidences + layout model score).
   * Low-confidence records go to a human operator page for correction; use the corrected examples to continually fine-tune models (active learning).

7. **Store & expose**

   * Store structured records in PostGIS (table with geometry column). Keep original scanned image and extraction JSON.
   * Index full text and entities in Elasticsearch/OpenSearch.
   * Serve spatial layers via GeoServer (WMTS/WMS/WFS) or serve vector tiles via TileServer GL.

8. **WebGIS & DSS integration**

   * Web app (React + OpenLayers/MapLibre) pulls layers from GeoServer and PostGIS.
   * The DSS engine reads asset layers (AI-mapped ponds, farmland, forest cover) and applies a ruleset + ML prioritization model to recommend CSS schemes; recommendations stored as attributes for each village/patta.

# Training & fine-tuning guidance

* **Data needs:** start with \~2k–5k annotated pages for pilot; more for production (10k+). Include representative samples of all states and scripts. Label at two levels: (1) transcription (line/text) for HTR; (2) key-value pairs on pages for LayoutLM/Donut fine-tuning.
* **HTR fine-tuning (TrOCR):**

  * Use Hugging Face `VisionEncoderDecoderModel` checkpoints for TrOCR as base.
  * Learning rate: `1e-5` to `5e-5`. Batch size depends on GPU memory (use gradient accumulation if needed). Train for few epochs (3–10) while monitoring CER (character error rate).
* **LayoutLMv3 / Donut:**

  * Use existing pre-trained checkpoint; fine-tune for key-value extraction.
  * Loss: cross-entropy on token labels or sequence2sequence (depending on model).
  * Monitor entity-level F1 and token-level accuracy.
* **NER:**

  * Fine-tune a multilingual transformer (XLM-RoBERTa / IndicBERT if available on-prem) for entity labels. Use gazetteers to boost recall for village/district names.
* **Active learning loop:** sample low-confidence or boundary cases for human labelling and add to training set iteratively.

# Evaluation metrics & thresholds

* **HTR:** CER (character error rate), WER. Target: CER < 5–10% for printed; aim <10–20% for challenging handwriting after fine-tune.
* **Entity extraction:** Precision/Recall/F1 for each field (Name, Village, Coordinates). Target: entity F1 > 0.90 for critical fields if possible.
* **Geolocation:** median geocoding error (meters) vs known ground truth; target <50m median for coords extracted from patta.
* **System:** percentage of records resolved without human intervention (automation rate) and time per human correction.

```bash
# Python snippet to run OCR on folder
from paddleocr import PaddleOCR, draw_ocr
import glob, cv2, json

ocr = PaddleOCR(lang='en')  # or 'multilingual' / config for Indic
results = {}
for img_path in glob.glob("scans/*.png"):
    res = ocr.ocr(img_path, cls=True)
    results[img_path] = res
    # Save boxes/text for downstream
with open("ocr_results.json","w") as f:
    json.dump(results, f)
```

**TrOCR inference (Hugging Face)**

```python
from transformers import TrOCRProcessor, VisionEncoderDecoderModel
from PIL import Image
import glob

processor = TrOCRProcessor.from_pretrained("microsoft/trocr-base-handwritten")
model = VisionEncoderDecoderModel.from_pretrained("microsoft/trocr-base-handwritten")

for img_path in glob.glob("handwritten/*.png"):
    pixel_values = processor(Image.open(img_path).convert("RGB"), return_tensors="pt").pixel_values
    generated_ids = model.generate(pixel_values, max_length=200)
    transcription = processor.batch_decode(generated_ids, skip_special_tokens=True)[0]
    print(img_path, transcription)
```
